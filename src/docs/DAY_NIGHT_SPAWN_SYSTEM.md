# Day/Night Spawn System

## Overview
The Day/Night Spawn System adds temporal awareness to the game's creature spawning mechanics. This allows the server to simulate a living ecosystem where nocturnal and diurnal creatures appear only during their respective active hours. The system manages both the initial spawning of creatures upon server startup and the continuous cycle of spawning and despawning (sleeping) based on the in-game time.

## Time Logic
The system relies on the game's internal light hour (`Game::getLightHour`) to determine the current phase of the day. The constants are defined in `src/game.h` (Public Constants):

| Phase | Start Time (Minutes) | Clock Time | Description |
| :--- | :--- | :--- | :--- |
| **Sunrise** | 300 | 05:00 | Transition from Night to Day starts. |
| **Day** | 600 | 10:00 | Full daylight. Diurnal active. |
| **Sunset** | 1020 | 17:00 | Transition from Day to Night starts. |
| **Night** | 1200 | 20:00 | Full darkness. Nocturnal active. |

*   **Day Duration:** 05:00 to 20:00 (15 hours)
*   **Night Duration:** 20:00 to 05:00 (9 hours)

## Monster Configuration
Monsters can be configured to be diurnal (Day), nocturnal (Night), or omnipresent (All). This is done via the `spawnType` attribute in the XML definition.

### Attribute: `spawnType`
*   **`day`**: The monster will only spawn if the current game time is between **05:00** and **20:00**.
*   **`night`**: The monster will only spawn if the current game time is **≥ 20:00** OR **< 05:00**.
*   **`all`** (Default): The monster ignores time restrictions and follows standard spawn intervals.

### How to Configure
You can add the `spawnType` attribute in the global `data/monster/monsters.xml` catalog (recommended for overriding) or in the individual monster file.

**Example (data/monster/monsters.xml):**
```xml
<?xml version="1.0" encoding="UTF-8"?>
<monsters>
    <!-- Nocturnal Monster -->
    <monster name="Zubat" file="pokes1/zubat.xml" spawnType="night" />
    
    <!-- Diurnal Monster -->
    <monster name="Pidgey" file="pokes1/pidgey.xml" spawnType="day" />
    
    <!-- Standard Monster (defaults to 'all') -->
    <monster name="Rattata" file="pokes1/rattata.xml" />
</monsters>
```

## System Mechanics

### 1. Smart Startup
When the server boots up, `Spawn::startup()` runs a check against the current server time.
*   If the server starts at **12:00 (Day)**, any spawn configured as `spawnType="night"` will be **skipped** during initialization.
*   This prevents the map from being flooded with nocturnal creatures immediately after a daytime restart.

### 2. Periodic Spawn Check
During the regular spawn interval (handled in `Spawn::checkSpawn()`):
*   Before spawning a new monster, the system verifies if the monster's `spawnType` matches the current `LightHour`.
*   If the time is wrong (e.g., trying to spawn a Zubat at noon), the spawn block is skipped for that cycle.

### 3. Cleanup (Sleep System)
To ensure the map reflects the current time, a cleanup mechanic runs periodically:
*   The system iterates through all active monsters generated by spawns.
*   It checks if they are currently "out of time" (e.g., a Day monster present during Night).
*   **Crucial Condition:** It checks if the monster is **Idle** (not fighting).
    *   If **Idle**: The monster is removed (despawned), simulating it going to sleep or hiding.
    *   If **In Combat**: The monster remains until the battle is finished. Once it leaves combat (or is killed), it won't respawn until its proper time comes again.

### 4. Force Check
Changing the world time manually (e.g., via commands) triggers `Spawns::checkSpawns()`. This forces an immediate re-evaluation of all spawns on the map, instantly creating/removing monsters to match the new time, verifying the idle rule.

## Testing
A talkaction command was created to facilitate testing the cycle.

**Command:** `/timetest [phase]`
**Access:** Gods/GMs

**Parameters:**
*   `morning` (Set time to 05:00)
*   `day` (Set time to 10:00)
*   `evening` (Set time to 17:00)
*   `night` (Set time to 20:00)
*   `midnight` (Set time to 23:59)

**Usage Example:**
1.  Go to an area with Zubats (configured as `night`).
2.  Say `/timetest day`.
3.  Observe existing idle Zubats vanishing.
4.  Kill any remaining Zubats. They will not respawn.
5.   Say `/timetest night`.
6.  Observe Zubats beginning to respawn.
